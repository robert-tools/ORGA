# shortcuts

### rt - robert.tools

installing npm lib from @robert.tools

```bash

rt status # get the status of all @robert.tools packages
rt outdated # check for outdated @robert.tools packages

rt curl
rt curl 1.0.4
rt curl latest
rt curl update

rt curl status # get the status of specific package

rt curl latest --save-dev
rt curl 1.0.4 --save-dev
```
